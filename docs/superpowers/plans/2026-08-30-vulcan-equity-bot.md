# Vulcan Equity Screener Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new paper-trading sleeve — weekly sector-momentum + RS/volume/stage equity rotation, ~20 names, traded via Alpaca paper equities — visible on the gods-eye dashboard.

**Architecture:** VPS-side Python bot (`quant-scrap/vulcan/`) computes theme rank → per-stock scoring → rebalance every Monday via cron, writing directly to Neon (`psycopg2`, same split as `quant-scrap/brain/options_db.py`). Next.js (Vercel) only reads Neon for the dashboard — no scoring or order placement happens on the web side.

**Tech Stack:** Python 3 (`requests`, `psycopg2`, `pandas` for the one-off universe scrape, `pytest`), TypeScript/Next.js (Drizzle ORM, existing `getPrice` market helper), Neon Postgres.

**Spec:** [docs/superpowers/specs/2026-08-30-vulcan-equity-bot-design.md](../specs/2026-08-30-vulcan-equity-bot-design.md)

## Global Constraints

- `TOP_N = 20`, `POSITION_NOTIONAL_USD = 250.0` — hardcoded constants, no settings UI (v1).
- Cron: `0 13 * * 1` (Monday 13:00 UTC) — matches the existing `dca` cron's UTC convention.
- No stop-loss/risk overlay, no SEC EDGAR signal, no live S&P500 feed (static bundled JSON) — all out of scope for v1.
- Any per-symbol Yahoo fetch failure is skipped, logged, never aborts the run (matches `yahoo.ts`/`wheel-chain.ts` convention).
- `strategy_key = "vulcan-equity"`, `mode = "paper"` for all `strategy_runs`/`strategy_events` audit rows.
- Sells execute before buys in every rebalance run.

```python
"""One-off script — regenerates quant-scrap/vulcan/sp500_universe.json from the
Wikipedia S&P 500 constituent table. Run manually when membership drifts (see
design doc "Universe" section — no live feed for v1).

Usage: python -m vulcan.build_universe
"""
from __future__ import annotations

import json
from pathlib import Path

import pandas as pd

WIKI_URL = "https://en.wikipedia.org/wiki/List_of_S%26P_500_companies"
OUTPUT = Path(__file__).parent / "sp500_universe.json"


def normalize_symbol(raw: str) -> str:
    """Wikipedia's table uses dotted share classes (BRK.B); Yahoo wants dashes."""
    return raw.strip().upper().replace(".", "-")


def build_universe() -> list[dict[str, str]]:
    table = pd.read_html(WIKI_URL)[0]
    return [
        {"symbol": normalize_symbol(str(row["Symbol"])), "sector": str(row["GICS Sector"]).strip()}
        for _, row in table.iterrows()
    ]


def main() -> None:
    rows = build_universe()
    OUTPUT.write_text(json.dumps(rows, indent=2))
    print(f"wrote {len(rows)} constituents to {OUTPUT}")


if __name__ == "__main__":
    main()
```

```python
"""Shared Yahoo Finance chart fetcher for vulcan (theme_rank.py + scoring.py).

Same unofficial endpoint gods-eye's Next.js side uses (src/lib/yahoo.ts) —
returns None on any failure so callers skip the name for that week, never
raising and aborting the whole weekly run over one bad ticker.
"""
from __future__ import annotations

from datetime import date, datetime
from typing import NamedTuple

import requests

CHART_BASE = "https://query1.finance.yahoo.com/v8/finance/chart"


class Bar(NamedTuple):
    date: date
    close: float
    volume: float


def fetch_daily_bars(symbol: str, range_: str, timeout: float = 8.0) -> list[Bar] | None:
    """Daily close+volume bars for `symbol`, oldest first. None on any fetch/parse failure."""
    try:
        r = requests.get(
            f"{CHART_BASE}/{symbol}",
            params={"range": range_, "interval": "1d"},
            headers={"User-Agent": "Mozilla/5.0"},
            timeout=timeout,
        )
        if r.status_code != 200:
            return None
        result = r.json()["chart"]["result"][0]
        ts = result.get("timestamp") or []
        quote = (result.get("indicators", {}).get("quote") or [{}])[0]
        closes = quote.get("close") or []
        volumes = quote.get("volume") or []
        bars: list[Bar] = []
        for i, t in enumerate(ts):
            close = closes[i] if i < len(closes) else None
            if close is None:
                continue
            volume = volumes[i] if i < len(volumes) else 0
            bars.append(Bar(date=datetime.utcfromtimestamp(t).date(), close=float(close), volume=float(volume or 0)))
        return bars if bars else None
    except (requests.RequestException, KeyError, IndexError, TypeError, ValueError):
        return None
```

- [ ] **Step 3: Write `theme_rank.py`**

```python
"""Step 1 of the weekly pipeline — rank the 11 GICS sectors by blended
equal-weight momentum, return the top 4. See design doc "Theme rank" section.
"""
from __future__ import annotations

from typing import Callable

MIN_SECTOR_CONSTITUENTS = 3  # sectors with fewer successfully-fetched names are skipped


def sector_momentum(closes_by_symbol: list[list[float]]) -> float | None:
    """Blended momentum (0.5 * 1mo return + 0.5 * 3mo return) of the equal-weight
    sector index built from each constituent's daily close series. Each series
    is normalized to 1.0 on its first day before averaging, so price scale
    (a $5 stock vs. a $500 stock) doesn't skew the equal weight.
    """
    if not closes_by_symbol:
        return None
    length = min(len(s) for s in closes_by_symbol)
    if length < 63:
        return None
    normed = [[p / s[0] for p in s[-length:]] for s in closes_by_symbol]
    index = [sum(day) / len(day) for day in zip(*normed)]
    ret_1mo = index[-1] / index[-22] - 1
    ret_3mo = index[-1] / index[-63] - 1
    return 0.5 * ret_1mo + 0.5 * ret_3mo


def rank_sectors(universe: list[dict], fetch_bars: Callable[[str], list | None]) -> list[tuple[str, float]]:
    """Sector -> blended momentum, sorted descending. `fetch_bars(symbol)` returns
    a list of objects with a `.close` attribute (e.g. `vulcan.yahoo_client.Bar`),
    or None on fetch failure (that name is dropped from its sector's average).
    """
    by_sector: dict[str, list[str]] = {}
    for row in universe:
        by_sector.setdefault(row["sector"], []).append(row["symbol"])

    momenta: list[tuple[str, float]] = []
    for sector, symbols in by_sector.items():
        closes: list[list[float]] = []
        for symbol in symbols:
            bars = fetch_bars(symbol)
            if bars:
                closes.append([b.close for b in bars])
        if len(closes) < MIN_SECTOR_CONSTITUENTS:
            continue
        m = sector_momentum(closes)
        if m is not None:
            momenta.append((sector, m))
    return sorted(momenta, key=lambda x: x[1], reverse=True)


def top_sectors(ranked: list[tuple[str, float]], n: int = 4) -> list[str]:
    return [sector for sector, _ in ranked[:n]]
```

```python
"""Step 2 of the weekly pipeline — RS percentile, U/D volume percentile, and
the binary Stage-2 gate, combined into a composite score. See design doc
"Per-stock scoring" section.
"""
from __future__ import annotations

from dataclasses import dataclass, replace

from vulcan.yahoo_client import Bar

RS_LOOKBACK_DAYS = 126     # ~6 trading months
UD_WINDOW_SESSIONS = 50
STAGE_SMA_WEEKS = 30
STAGE_SLOPE_LAG_WEEKS = 5
MIN_WEEKS_FOR_STAGE_GATE = STAGE_SMA_WEEKS + STAGE_SLOPE_LAG_WEEKS


def percentile_rank(value: float, population: list[float]) -> float:
    """0-100 percentile rank of `value` within `population` (average-rank method
    for ties: below-count plus half the equal-count, divided by population size)."""
    n = len(population)
    if n == 0:
        return 0.0
    below = sum(1 for p in population if p < value)
    equal = sum(1 for p in population if p == value)
    return (below + 0.5 * equal) / n * 100


def total_return(bars: list[Bar], lookback: int) -> float | None:
    if len(bars) <= lookback:
        return None
    return bars[-1].close / bars[-1 - lookback].close - 1


def up_down_ratio(bars: list[Bar]) -> float | None:
    """sum(volume on up days) / sum(volume on down days) over the trailing
    UD_WINDOW_SESSIONS sessions. Flat days count toward neither sum. None if
    there isn't a full window, or if there's no down-volume (ratio undefined)."""
    window = bars[-(UD_WINDOW_SESSIONS + 1):]
    if len(window) < UD_WINDOW_SESSIONS + 1:
        return None
    up_vol = down_vol = 0.0
    for prev, cur in zip(window, window[1:]):
        if cur.close > prev.close:
            up_vol += cur.volume
        elif cur.close < prev.close:
            down_vol += cur.volume
    if down_vol == 0:
        return None
    return up_vol / down_vol


def _weekly_last_closes(bars: list[Bar]) -> list[float]:
    """Last close of each ISO week, in chronological order. Requires `bars` to
    already be chronologically ascending."""
    by_week: dict[tuple[int, int], float] = {}
    order: list[tuple[int, int]] = []
    for bar in bars:
        key = bar.date.isocalendar()[:2]
        if key not in by_week:
            order.append(key)
        by_week[key] = bar.close
    return [by_week[k] for k in order]


def _simple_moving_average(values: list[float], window: int) -> list[float]:
    if len(values) < window:
        return []
    return [sum(values[i - window:i]) / window for i in range(window, len(values) + 1)]


def stage2_eligible(bars: list[Bar]) -> bool | None:
    """Weekly-resampled 30-week SMA + 5-week slope. Eligible iff price > SMA30w
    AND the SMA is still rising (SMA[t] > SMA[t-5]). None if there isn't enough
    weekly history yet."""
    weekly = _weekly_last_closes(bars)
    if len(weekly) < MIN_WEEKS_FOR_STAGE_GATE:
        return None
    sma = _simple_moving_average(weekly, STAGE_SMA_WEEKS)
    if len(sma) < STAGE_SLOPE_LAG_WEEKS + 1:
        return None
    slope = sma[-1] - sma[-1 - STAGE_SLOPE_LAG_WEEKS]
    price = weekly[-1]
    return price > sma[-1] and slope > 0


@dataclass(frozen=True)
class Score:
    symbol: str
    sector: str
    rs_percentile: float
    ud_ratio: float
    ud_percentile: float
    stage2_eligible: bool
    composite_score: float
    composite_rank: int | None


def score_universe(
    bars_by_symbol: dict[str, list[Bar] | None],
    sector_by_symbol: dict[str, str],
    top_n: int = 20,
) -> list[Score]:
    """Score every name with usable data (RS uses percentile rank against this
    week's scoring universe, not the full S&P500). Stage-2 gate is applied
    AFTER scoring so percentiles stay meaningful against the full universe,
    then the top `top_n` by composite score are taken from the eligible subset."""
    rs_by_symbol: dict[str, float] = {}
    ud_by_symbol: dict[str, float] = {}
    stage_by_symbol: dict[str, bool] = {}
    for symbol, bars in bars_by_symbol.items():
        if not bars:
            continue
        rs = total_return(bars, RS_LOOKBACK_DAYS)
        ud = up_down_ratio(bars)
        stage = stage2_eligible(bars)
        if rs is None or ud is None or stage is None:
            continue
        rs_by_symbol[symbol] = rs
        ud_by_symbol[symbol] = ud
        stage_by_symbol[symbol] = stage

    rs_population = list(rs_by_symbol.values())
    ud_population = list(ud_by_symbol.values())

    scores: list[Score] = []
    for symbol in rs_by_symbol:
        rs_pct = percentile_rank(rs_by_symbol[symbol], rs_population)
        ud_pct = percentile_rank(ud_by_symbol[symbol], ud_population)
        scores.append(
            Score(
                symbol=symbol,
                sector=sector_by_symbol.get(symbol, "Unknown"),
                rs_percentile=rs_pct,
                ud_ratio=ud_by_symbol[symbol],
                ud_percentile=ud_pct,
                stage2_eligible=stage_by_symbol[symbol],
                composite_score=(rs_pct + ud_pct) / 2,
                composite_rank=None,
            )
        )

    eligible = sorted((s for s in scores if s.stage2_eligible), key=lambda s: s.composite_score, reverse=True)
    top_symbols = {s.symbol for s in eligible[:top_n]}
    ranked = [replace(s, composite_rank=i) for i, s in enumerate(eligible[:top_n], start=1)]
    others = [s for s in scores if s.symbol not in top_symbols]
    return ranked + others
```

```python
"""Minimal REST client for plain equity paper orders — no options SDK needed.
Same paper endpoint alpaca.ts uses (https://paper-api.alpaca.markets), but
without position_intent (options-only) or contract multipliers.
"""
from __future__ import annotations

from dataclasses import dataclass

import requests


@dataclass(frozen=True)
class OrderResult:
    ok: bool
    filled_price: float | None = None
    error: str | None = None


class AlpacaEquity:
    def __init__(self, base_url: str, key_id: str, secret_key: str, timeout: float = 10.0):
        self.base_url = base_url.rstrip("/")
        self.headers = {
            "APCA-API-KEY-ID": key_id,
            "APCA-API-SECRET-KEY": secret_key,
            "Content-Type": "application/json",
        }
        self.timeout = timeout

    def get_account(self) -> dict:
        r = requests.get(f"{self.base_url}/v2/account", headers=self.headers, timeout=self.timeout)
        r.raise_for_status()
        return r.json()

    def get_positions(self) -> list[dict]:
        r = requests.get(f"{self.base_url}/v2/positions", headers=self.headers, timeout=self.timeout)
        r.raise_for_status()
        return r.json()

    def market_sell(self, symbol: str, qty: float) -> OrderResult:
        return self._order({"symbol": symbol, "qty": str(qty), "side": "sell", "type": "market", "time_in_force": "day"})

    def market_buy_notional(self, symbol: str, notional_usd: float) -> OrderResult:
        return self._order({"symbol": symbol, "notional": str(notional_usd), "side": "buy", "type": "market", "time_in_force": "day"})

    def _order(self, body: dict) -> OrderResult:
        try:
            r = requests.post(f"{self.base_url}/v2/orders", headers=self.headers, json=body, timeout=self.timeout)
        except requests.RequestException as e:
            return OrderResult(ok=False, error=str(e))
        if r.status_code >= 300:
            return OrderResult(ok=False, error=f"HTTP {r.status_code}: {r.text[:200]}")
        data = r.json()
        filled_price = float(data["filled_avg_price"]) if data.get("filled_avg_price") else None
        return OrderResult(ok=True, filled_price=filled_price)
```

```python
"""Step 3 of the weekly pipeline — diff this week's top N against currently-held
vulcan_positions, sell drop-outs, buy new entrants. See design doc "Rebalance"
section. Free of DB/journaling concerns — callers pass callbacks so vulcan_db
writes stay in run.py.
"""
from __future__ import annotations

from dataclasses import dataclass
from typing import Callable

from vulcan.alpaca_equity import AlpacaEquity


@dataclass(frozen=True)
class RebalancePlan:
    drop_outs: list[str]
    new_entrants: list[str]
    held: list[str]


def plan_rebalance(top_n_symbols: list[str], held_symbols: list[str]) -> RebalancePlan:
    held_set = set(held_symbols)
    top_set = set(top_n_symbols)
    return RebalancePlan(
        drop_outs=sorted(held_set - top_set),
        new_entrants=sorted(top_set - held_set),
        held=sorted(held_set & top_set),
    )


def execute_rebalance(
    plan: RebalancePlan,
    broker: AlpacaEquity,
    positions_by_symbol: dict[str, float],
    notional_usd: float,
    on_sell: Callable[[str, float, float | None], None],
    on_buy: Callable[[str, float, float | None], None],
    on_skip: Callable[[str, str], None],
) -> None:
    """Sells drop-outs first (frees buying power), then buys new entrants. A
    failed buy is skipped and logged via `on_skip`, not raised — the rest of
    the rebalance still runs."""
    for symbol in plan.drop_outs:
        qty = positions_by_symbol.get(symbol)
        if not qty:
            continue
        result = broker.market_sell(symbol, qty)
        if result.ok:
            on_sell(symbol, qty, result.filled_price)
        else:
            on_skip(symbol, result.error or "sell failed")

    for symbol in plan.new_entrants:
        result = broker.market_buy_notional(symbol, notional_usd)
        if result.ok:
            on_buy(symbol, notional_usd, result.filled_price)
        else:
            on_skip(symbol, result.error or "buy failed")
```

```python
        if not line or line.startswith("#") or "=" not in line:
```

```python
from vulcan import vulcan_db
from vulcan.alpaca_equity import AlpacaEquity
from vulcan.rebalance import execute_rebalance, plan_rebalance
from vulcan.scoring import score_universe
from vulcan.theme_rank import rank_sectors, top_sectors
from vulcan.yahoo_client import fetch_daily_bars

UNIVERSE_FILE = Path(__file__).parent / "sp500_universe.json"
TOP_N = 20
POSITION_NOTIONAL_USD = 250.0
SCORING_RANGE = "1y"   # needs ~35 weeks of history for the stage gate
SECTOR_RANGE = "6mo"   # needs ~63 trading days for the 3mo momentum leg


def main() -> None:
    vulcan_db.load_env()

    universe = json.loads(UNIVERSE_FILE.read_text())
    sector_by_symbol = {row["symbol"]: row["sector"] for row in universe}

    ranked_sectors = rank_sectors(universe, fetch_bars=lambda s: fetch_daily_bars(s, SECTOR_RANGE))
    top4 = top_sectors(ranked_sectors, n=4)
    scoring_universe = [row for row in universe if row["sector"] in top4]

    bars_by_symbol = {row["symbol"]: fetch_daily_bars(row["symbol"], SCORING_RANGE) for row in scoring_universe}
    scores = score_universe(bars_by_symbol, sector_by_symbol, top_n=TOP_N)

    run_date = date.today().isoformat()
    vulcan_db.insert_scores(run_date, scores)

    top20 = [s.symbol for s in scores if s.composite_rank is not None]
    held = vulcan_db.get_open_positions()
    plan = plan_rebalance(top20, [h.symbol for h in held])
    positions_by_symbol = {h.symbol: h.qty for h in held}

    broker = AlpacaEquity(
        base_url="https://paper-api.alpaca.markets",
        key_id=os.environ["ALPACA_API_KEY_ID"],
        secret_key=os.environ["ALPACA_API_SECRET_KEY"],
    )

    vulcan_db.ensure_strategy_run()
    now = datetime.now(timezone.utc)

    def on_sell(symbol: str, qty: float, price: float | None) -> None:
        vulcan_db.record_exit(symbol, price or 0.0, now)
        vulcan_db.append_trade_event(symbol, "sell", qty, price, f"vulcan:{run_date}:{symbol}:sell")

    def on_buy(symbol: str, notional: float, price: float | None) -> None:
        qty = notional / price if price else 0.0
        vulcan_db.record_entry(symbol, qty, price or 0.0, now)
        vulcan_db.append_trade_event(symbol, "buy", qty, price, f"vulcan:{run_date}:{symbol}:buy")

    def on_skip(symbol: str, reason: str) -> None:
        print(f"[vulcan] skip {symbol}: {reason}")

    execute_rebalance(plan, broker, positions_by_symbol, POSITION_NOTIONAL_USD, on_sell, on_buy, on_skip)
    print(f"[vulcan] run complete: {len(top20)} ranked, {len(plan.new_entrants)} bought, {len(plan.drop_outs)} sold")


if __name__ == "__main__":
    main()
```

```ts
import "server-only";
import { and, desc, eq, sql } from "drizzle-orm";
import { db } from "@/db/client";
import { vulcan_positions, vulcan_scores } from "@/db/schema";
import { getPrice } from "@/lib/market";

export type VulcanHoldingRow = {
  symbol: string;
  qty: number;
  entryPrice: number;
  entryDate: string;
  currentPrice: number | null;
  value: number | null;
  pnl: number | null;
  pnlPct: number | null;
};

export type VulcanCandidateRow = {
  symbol: string;
  sector: string;
  compositeScore: number;
  compositeRank: number | null;
  stage2Eligible: boolean;
  held: boolean;
};

export type VulcanDashboardData = {
  holdings: VulcanHoldingRow[];
  totalValue: number;
  totalPnl: number;
  latestRunDate: string | null;
  candidates: VulcanCandidateRow[];
};

export async function getVulcanDashboardData(userId: string): Promise<VulcanDashboardData> {
  const openRows = await db
    .select()
    .from(vulcan_positions)
    .where(and(eq(vulcan_positions.user_id, userId), eq(vulcan_positions.still_open, true)));

  const prices = await Promise.all(
    openRows.map((r) => getPrice(r.symbol, "equity").then((d) => d?.price ?? null).catch(() => null)),
  );

  const holdings: VulcanHoldingRow[] = openRows.map((r, i) => {
    const qty = parseFloat(r.qty);
    const entryPrice = parseFloat(r.entry_price);
    const currentPrice = prices[i];
    const value = currentPrice != null ? qty * currentPrice : null;
    const cost = qty * entryPrice;
    const pnl = value != null ? value - cost : null;
    return {
      symbol: r.symbol,
      qty,
      entryPrice,
      entryDate: r.entry_date.toISOString(),
      currentPrice,
      value,
      pnl,
      pnlPct: pnl != null && cost > 0 ? (pnl / cost) * 100 : null,
    };
  });

  const totalValue = holdings.reduce((s, h) => s + (h.value ?? 0), 0);
  const totalPnl = holdings.reduce((s, h) => s + (h.pnl ?? 0), 0);

  const latestRow = await db.select({ d: sql<string | null>`max(${vulcan_scores.run_date})` }).from(vulcan_scores);
  const latestRunDate = latestRow[0]?.d ?? null;

  const heldSymbols = new Set(holdings.map((h) => h.symbol));
  let candidates: VulcanCandidateRow[] = [];
  if (latestRunDate) {
    const rows = await db
      .select()
      .from(vulcan_scores)
      .where(eq(vulcan_scores.run_date, latestRunDate))
      .orderBy(desc(vulcan_scores.composite_score));
    candidates = rows.map((r) => ({
      symbol: r.symbol,
      sector: r.sector,
      compositeScore: parseFloat(r.composite_score),
      compositeRank: r.composite_rank,
      stage2Eligible: r.stage2_eligible,
      held: heldSymbols.has(r.symbol),
    }));
  }

  return { holdings, totalValue, totalPnl, latestRunDate, candidates };
}
```

```tsx
                <tr key={h.symbol} className="dotted-row">
                  <td className="py-1 text-white font-bold">{h.symbol}</td>
                  <td className="py-1 text-right tabular-nums text-muted">{h.qty.toFixed(2)}</td>
                  <td className="py-1 text-right tabular-nums text-dim">{usd(h.entryPrice)}</td>
                  <td className="py-1 text-right tabular-nums text-dim">
                    {h.currentPrice != null ? usd(h.currentPrice) : "—"}
                  </td>
                  <td className={`py-1 text-right tabular-nums font-bold ${
                    (h.pnl ?? 0) >= 0 ? "text-green" : "text-red"
                  }`}>
                    {h.pnl != null ? `${h.pnl >= 0 ? "+" : ""}${usd(h.pnl)}` : "—"}
                    {h.pnlPct != null && (
                      <span className="text-[11px] font-normal text-dim"> ({h.pnlPct >= 0 ? "+" : ""}{h.pnlPct.toFixed(1)}%)</span>
                    )}
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        ) : (
          <div className="text-dim text-[12px] italic py-2">No open positions — runs weekly (Mondays UTC).</div>
        )}
      </div>

      {/* Ranked candidates */}
      <div className="border border-border bg-grid p-3 mb-3">
        <div className="text-muted text-[12px] mb-2 uppercase tracking-[1px]">
          RANKED CANDIDATES {data.latestRunDate ? `— ${data.latestRunDate}` : ""}
        </div>
        {topCandidates.length > 0 ? (
          <table className="w-full text-[12px]">
            <thead>
              <tr className="text-dim text-[12px] uppercase tracking-[1px]">
                <td className="py-1">Rank</td>
                <td className="py-1">Symbol</td>
                <td className="py-1">Sector</td>
                <td className="py-1 text-right">Score</td>
                <td className="py-1 text-right">Stage-2</td>
                <td className="py-1 text-right">Held</td>
              </tr>
            </thead>
            <tbody>
              {topCandidates.map((c) => (
                <tr key={c.symbol} className="dotted-row">
                  <td className="py-1 text-dim tabular-nums">{c.compositeRank ?? "—"}</td>
                  <td className="py-1 text-white font-bold">{c.symbol}</td>
                  <td className="py-1 text-muted">{c.sector}</td>
                  <td className="py-1 text-right tabular-nums text-amber">{c.compositeScore.toFixed(1)}</td>
                  <td className={`py-1 text-right ${c.stage2Eligible ? "text-green" : "text-dim"}`}>
                    {c.stage2Eligible ? "✓" : "—"}
                  </td>
                  <td className={`py-1 text-right ${c.held ? "text-cyan" : "text-dim"}`}>{c.held ? "●" : "—"}</td>
                </tr>
              ))}
            </tbody>
          </table>
        ) : (
          <div className="text-dim text-[12px] italic py-2">No scored run yet — first run publishes Monday 13:00 UTC.</div>
        )}
      </div>

      {/* How it works */}
      <div className="border border-border/40 bg-grid p-3 text-[12px] text-dim leading-relaxed">
        <span className="text-muted">◎ HOW IT WORKS</span> — Weekly: rank the 11 GICS sectors by
        blended 1mo/3mo equal-weight momentum, take the top 4 sectors' constituents (~150-200
        names). Score each on relative-strength percentile (6mo return) and up/down volume
        percentile (50-session), gated by a binary Stage-2 filter (price above a rising 30-week
        SMA). Top 20 by composite score, equal-weight $250 positions via Alpaca paper, rotated
        out on rank drop. No stop-loss — pure rank-rotation. Not financial advice.
      </div>
    </>
  );
}
```
